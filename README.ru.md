# Репетитор по русскому языку — ОГЭ и ЕГЭ (Windows)

Приложение для Windows 10/11 (x64), .NET 8 WPF, самодостаточная сборка (ставить .NET не нужно).

## Что внутри
- **Тренажёр**: банк авторских заданий по номерам ЕГЭ 1–26 и ОГЭ 2–12 в формате ФИПИ 2026, автопроверка (набор цифр в любом порядке, соответствие по порядку, слово), объяснение, ссылка на теорию, «Объяснить через GigaChat».
- **Умная тренировка**: адаптивный подбор — номера с низким процентом верных и задания с ошибками выпадают чаще.
- **Генерация новых заданий** через GigaChat по выбранному номеру (сохраняются в `%APPDATA%\RusTutor\my-tasks.json`).
- **Работа над ошибками**: интервальное повторение SM-2 (1 → 3 → 7+ дней), каждая ошибка становится карточкой.
- **Пробный экзамен**: вариант из банка (по заданию на номер), таймер 3 ч 55 мин, результат и разбор.
- **Сочинение и изложение**: ЕГЭ №27 (К1–К10, 22 балла, ≥150 слов), ОГЭ №13 (СК1–СК4 + ГК/ФК, ≥70 слов), ОГЭ №1 изложение (ИК1–ИК3) — проверка GigaChat по критериям, таблица баллов, список ошибок, отзыв.
- **Теория**: 30 разделов (орфоэпия, паронимы, нормы, орфография, пунктуация, тропы, критерии, методика подготовки).
- **Главная**: статистика, освоение каждого номера, серия дней, история экзаменов и сочинений.
- **Ввод ответа**: клавиатура, 🎤 голос (Google, ru-RU), ✍ рукописный ввод (перо, сенсор, тачпад/мышь).

## GigaChat
1. **Веб-чат (по умолчанию)** — вкладка «🤖 GigaChat» со встроенным браузером (WebView2) открывает giga.chat. Один раз войдите в аккаунт — вход сохраняется. Программа сама вставляет промпт, отправляет, ждёт окончания ответа, берёт последний блок кода, вычищает ссылки поиска и разбирает JSON (`score`, `max`, `criteria`, `errors`, `explanation`). Кнопка «Проверить автоматизацию» — быстрый тест. Если сайт поменяет вёрстку, поправьте CSS-селекторы в «Настройках».
2. **Официальный API** — «Настройки» → «Официальный GigaChat API», вставьте Authorization key из developers.sber.ru (scope GIGACHAT_API_PERS для физлиц). Нужен корневой сертификат НУЦ Минцифры в Windows (или галочка «не проверять сертификат» — небезопасно).

## Рукописный ввод
Кнопка ✍ открывает холст InkCanvas. «Распознать (Windows)» использует встроенный распознаватель Windows (Windows.UI.Input.Inking) — нужен установленный компонент «Рукописный ввод» для русского языка (Параметры → Время и язык → Язык → Русский → Параметры). Если его нет или результат пустой, рисунок отправляется картинкой в GigaChat (через API — надёжно; через веб-чат — попытка вставить картинку, зависит от сайта). Распознанный текст можно поправить перед вставкой.

## Голос
Код взят из VoiceType: бесплатный режим Google (без ключа, как recognize_google; Google может ограничивать частоту) или Google Cloud Speech-to-Text (API-ключ или JSON сервисного аккаунта) с пунктуацией.

## Данные
`%APPDATA%\RusTutor\` — settings.json, progress.json, my-tasks.json. Профиль браузера — `%LOCALAPPDATA%\RusTutor\WebView2`.

Структура экзаменов и критерии — по демоверсиям/спецификациям ФИПИ 2026 (fipi.ru). Задания банка составлены заново, не скопированы. Оценки ИИ ориентировочные.
